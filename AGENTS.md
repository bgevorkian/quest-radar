# Работа над QuestRadar

Перед изменениями прочитай `README.md` и `DEVELOPMENT.md`. Последний содержит карту кода, порядок проверки и установки, ограничения и состояние на дату передачи. Сверяй его с текущими файлами; числа и версия могут измениться.

- Цель: небольшой помощник, показывающий места получения доступных персонажу заданий на большой карте WoW Forever. По запросу пользователя добавлены городские службы на большой карте и сообщения об ошибках. Не расширяй его до комбайна или замены журнала заданий.
- Внешний вид должен следовать Blizzard. Штатные значки, шрифты, цвета сложности и настройки. На карте нет брендинга, ID, технических причин и сведений об ATT. Обычная подсказка: `[уровень задания] Название`.
- Настройки и отчёт открываются через штатное меню «Модификации» у миникарты. Не возвращай отдельную кнопку миникарты или кнопки поверх карты без нового запроса пользователя.
- Отсутствие предшественников в ATT само по себе не делает задание серым: проверяем записанный уровень и остальные известные условия. Подставленный по умолчанию уровень 1 не считается доказательством. Не называй расчёт по ATT подтверждённой сервером доступностью.
- Не правь `upstream/AllTheThings` и сгенерированный `QuestRadar/Data.lua` и `QuestRadar/ServiceData.lua` вручную. Исправляй импорт или `data/corrections.json`, записывая основание поправки, затем пересоздавай базу.
- Поддержка всех импортированных локаций уже включена. Зефрис — площадка игровой проверки, а не ограничение импорта.
- Проверяй API именно Forever: совпадение с Retail или Classic не гарантируется. Не добавляй зависимости в игру без необходимости.
- После изменения логики запускай соответствующие проверки из README. Имитированные API не заменяют проверку в клиенте. Не утверждай, что проверил поведение в игре, если проверял только Python/Lua.
- Перед установкой сохраняй копии заменяемых файлов. Не трогай пользовательские SavedVariables и соседние аддоны. После установки сверяй байты файлов и указывай пользователю `/reload`.
- Обновляй документацию при изменении правил, структуры или установки. Не смешивай этот проект с работой над озвучкой Wayfarer.
