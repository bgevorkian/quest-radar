# QuestRadar 0.2.15

Для продолжения разработки: [правила работы](AGENTS.md) и [памятка по коду, установке и ограничениям](DEVELOPMENT.md).

Аддон для WoW Forever (Interface 16001). Показывает на большой карте места получения заданий из ATT, учителей и городские службы. Проверяет известные условия заданий для текущего персонажа. Первая игровая проверка — на Зефрисе; база включает и другие локации. Зависимости в игре не нужны.

## Проверка в игре

Папка `QuestRadar` должна лежать в `_classic_beta_/Interface/AddOns/`. После обновления введите `/reload`. Если аддон не появился в списке, перезапустите клиент.

Откройте карту Зефриса. Настройки открываются через штатное меню «Модификации» у миникарты: выберите QuestRadar. Галочки управляют всеми отметками, сомнительными заданиями, городскими службами и обычными торговцами. «Выгрузить отчёт» открывает текст для копирования; «Сообщить об ошибке» записывает место и NPC автоматически. Наведение показывает `[уровень задания] Название` с цветом сложности WoW. Если уровень ещё неизвестен, используется `[?]`. Для неуточнённых условий добавляется одна короткая строка. ID и технические причины остаются в отчёте.

- Золотой `!`: известные условия ATT выполнены. Это расчёт по неполной базе, а не подтверждение сервера.
- Серый `!`: часть условий неизвестна или требует проверки. Эти отметки можно скрыть отдельно.
- Подтверждение в подсказке жёлтого `!`: NPC предложил задание при недавнем разговоре. Подтверждение действует минуту и сбрасывается при изменении прогресса. Координаты разговора — позиция игрока рядом с NPC.

Уже взятые и выполненные обычные задания скрываются. Повторяемые требуют отдельной проверки. Если предшественники не указаны, проверяется записанный уровень или другое известное условие открытия. Если не записано ни одно такое условие, значок серый. Технически подставленный уровень 1 не считается известным условием; для Зефриса уровни восстанавливаются из исходника ATT. Это предположение по базе; неизвестные серверные условия могут дать ложную отметку. Серый цвет используется для явных непроверенных условий, предметов начала задания, повторяемости или недоступного состояния персонажа. Задания без координат не получают отметку. Из наблюдений аддон не выводит новые условия автоматически.

Отдельной кнопки QuestRadar у миникарты нет. Включение отметок и открытие отчёта доступны в настройках.

Команды:

- `/qradar` — включить/выключить отметки.
- `/qradar uncertain` — показать/скрыть сомнительные.
- `/qradar settings` — открыть настройки.
- `/qradar report` — общий отчёт для отправки; Ctrl+A, Ctrl+C для копирования.
- `/qradar bug` — сообщить об ошибке с автоматически записанным местом.
- `/qradar scan` — отдельная диагностика C_QuestLine для открытой карты, результат через 8 секунд.
- `/qradar 2521` — диагностика API указанной карты.
- `/qradar clear` — очистить сохранённый отчёт диагностики API.

Для проверки сравните отметки с предложениями NPC, возьмите квест и проверьте исчезновение его отметки. При неверном результате сохраните `/qradar report` и скриншот разговора.

## Городские службы

На картах городов и поселений отображаются известные банкиры, аукционисты, учителя классов и профессий, ремонт, почта, трактирщики, распорядители полётов, смотрители стойл, военачальники и торговцы. Используются штатные атласы значков миникарты, сверенные с таблицей клиента Forever 1.60.1.70170. Они не зависят от включённых фильтров отслеживания. Обычные торговцы отмечены штатным значком покупки Blizzard; значок реагентов им не назначается. Подсказка показывает имя NPC и его занятие, например «Учитель кузнечного дела». Учителя других классов и NPC противоположной фракции скрываются. Близкие точки одного типа объединяются; в подсказке перечисляются службы и NPC группы.

В базе 1445 NPC и объектов, 1944 точки на 50 картах. Это покрытие источников, а не полный проверенный список всех служб Forever. Основные данные взяты из [Waypoint Tracker](https://github.com/sanjaygbhat/wowforever-waypoint-tracker), включая данные pfQuest и наблюдения игроков Forever; специальности учителей дополнены по явным подписям ATT. Классические координаты пересчитаны по геометрии карт Forever, наблюдения Forever заменяют старые точки на соответствующих картах. Пересчёт не доказывает, что NPC остался на прежнем месте. У части учителей направление пока неизвестно. Новые или перемещённые NPC могут отсутствовать. Источники, ревизии и ограничения записаны в `research/service-import-summary.json`.

Поправки для Зефриса записаны в `data/service-corrections.json`: учителя классов и профессий, трактирщики, ремонт и стойла. Координаты взяты из опубликованных маршрутов RestedXP и [обзора Зефриса](https://www.wowhead.com/forever/guide/zephras-isle-zone-overview); русские имена сверены с NPC-кэшем клиента. Источник указан у каждой записи. Позиции банка, аукциона и почты на Зефрисе пока не добавлены: подтверждённых координат в используемой базе нет.

Слой служб и обычных торговцев можно отключить отдельно в настройках. Если в клиенте недоступен штатный атлас категории, такие отметки пропускаются; категория попадёт в `services.missingIcons` отчёта. Данные и логика встроены в QuestRadar, устанавливать Waypoint Tracker, pfQuest или ATT в игру не требуется.

## Сообщить об ошибке

1. Останьтесь возле проблемного места. Если ошибка касается NPC, выберите его целью или откройте разговор с ним.
2. В меню «Модификации» → QuestRadar нажмите «Сообщить об ошибке» или введите `/qradar bug`.
3. Выберите «Нет отметки», «Неверное место», «Неверный NPC / услуга» или «Другая проблема». Комментарий необязателен.
4. Нажмите «Сохранить и открыть отчёт», затем Ctrl+A, Ctrl+C. Отправьте скопированный текст разработчику.

Для сообщения о конкретной отметке нажмите на неё левой кнопкой с зажатым Shift. Форма дополнительно сохранит саму отметку и её координаты, даже если персонаж находится далеко.

Локация, координаты игрока, время, NPC, характеристики персонажа и версии данных фиксируются при открытии формы. В форме видно записанное место; перемещение персонажа после её открытия не меняет сообщение. Если игра не отдала координаты или NPC не выбран, аддон сохраняет остальные доступные сведения. Собственные имена и GUID персонажей в новых сообщениях не собираются; в свободный комментарий пользователь пишет только то, что хочет отправить.

«Выгрузить отчёт» и `/qradar report` работают и без ручного сообщения. Общий отчёт включает неизвестные принятые задания, предложения NPC, наблюдения служб, ручные сообщения и текущую диагностику. Сообщения и наблюдения остаются после копирования и `/reload`; копирование не означает отправку. `/qradar clear` очищает только отдельную диагностику API.

При открытии торговли, обучения, банка, аукциона, полётов, стойл или привязки к трактиру аддон записывает наблюдение, если клиент передал NPC. Простой проход мимо NPC не создаёт запись: требуется взаимодействие. Хранится последнее наблюдение на пару NPC/служба. Отмечается, есть ли NPC в базе и есть ли рядом известная точка. Расхождение помогает искать ошибки, но не доказывает их: записана позиция игрока при разговоре, не точная позиция NPC. Наблюдения автоматически не меняют отметки.

## Данные и обновление

Исходники аддона и сгенерированные базы входят в этот репозиторий. Чтобы пересоздать базы, сначала подготовьте источники:

```bash
mkdir -p upstream
git clone https://github.com/ATTWoWAddon/AllTheThings.git upstream/AllTheThings
git clone https://github.com/sanjaygbhat/wowforever-waypoint-tracker.git upstream/WaypointTracker
```

Для воспроизведения текущей базы служб используйте ревизии из `research/service-import-summary.json`. Сначала выполните импорт заданий: `uv run --with lupa python tools/import_att.py`, затем импорт служб: `python3 tools/import_services.py`. Импорт служб читает созданное первым шагом дерево категорий ATT, чтобы определить торговцев. Его геометрия хранится в `data/service-map-geometry.json`; её источник указан внутри файла. `QuestRadar/ServiceData.lua` не редактируется вручную. Лицензии источников включены в `QuestRadar/LICENSE-Services.txt`.

Полный Git-клон [AllTheThings](https://github.com/ATTWoWAddon/AllTheThings) находится в `upstream/AllTheThings`. Его файлы не редактируем. Импортируются обычные категории из `db/Camelot`; скрытые триггеры, Unsorted и NeverImplemented исключены. Условия родительских групп учитываются. Лицензия MIT и уведомление авторов включены в `QuestRadar/LICENSE-ATT.txt`.

Сводка импорта: `research/import-summary.json`; ревизия также записана в `QuestRadar/Data.lua`. Текущий импорт: 4357 ID, из них 3980 с координатами, 49 карт. Эти числа не означают полноту базы или проверку доступности всех заданий.

Из каталога проекта:

```bash
git -C upstream/AllTheThings pull --ff-only
uv run --with lupa python tools/import_att.py
uv run --with lupa python tools/audit_zephras.py
uv run --with lupa python tests/rules.py
uv run --with lupa python tests/map.py
uv run --with lupa python tests/check.py
uv run --with lupa python tests/services_data.py
```

После импорта обновите папку аддона в игре. `git pull` сам по себе не меняет установленный аддон; фонового обновления нет. Python и lupa нужны только для импорта и проверок вне игры.

Исходные Forever-данные ATT лежат в `.contrib/.db/forever/`. Исходники и сгенерированная база `db/Camelot` могут различаться. Проверенные поправки хранятся в `data/corrections.json` вместе с основанием и применяются при каждом импорте. Отсутствие цепочки само по себе не превращает задание в подтверждённое стартовое.

## Сохранение данных

Настройки, диагностика, ручные сообщения об ошибках, наблюдения служб и до 200 наблюдений предложений NPC сохраняются отдельно для каждого персонажа. Наблюдения содержат ID квеста и NPC, позицию игрока, время, уровень, класс, расу и фракцию. Они не доказывают полный набор условий получения. Подтверждения NPC между сессиями не сохраняются. Аддон ничего никуда не отправляет.

При принятии задания, ID которого отсутствует в базе аддона, QuestRadar сохраняет первую запись об этом задании в `QuestRadarUnknownQuests`. В ней есть ID, доступное название, время, уровень/класс/раса/фракция персонажа, версия аддона, ревизия базы и версия клиента. Карта и позиция игрока записываются, если доступны; NPC указывается только по недавнему наблюдению предложения этого задания. Отсутствие координат или NPC не мешает сбору. Имя персонажа не записывается. Повторное принятие того же ID не добавляет запись; обновление базы не удаляет ранее собранные данные. Сбор работает и при выключенных отметках карты, начиная с установки этой версии.

Клиент сохраняет данные на диск при `/reload` или обычном выходе. Для передачи сделайте `/reload` и отправьте файл из папки игры:

```text
_classic_beta_\WTF\Account\<аккаунт>\<сервер>\<персонаж>\SavedVariables\QuestRadar.lua
```

Это файл сохранений, не одноимённый исходник из `Interface\AddOns`. В нём также лежат настройки и прежняя диагностика QuestRadar. Можно отправить текст `/qradar report`, где сбор находится в `unknownQuests`. Способ отправки выбирает пользователь. `/qradar clear` очищает диагностику API, но не сбор неизвестных заданий. Принятие задания подтверждает сам факт получения; координаты игрока не считаются координатами выдающего NPC и не создают отметку автоматически.

Проверка сбора в клиенте: принять отсутствующее в базе задание, убедиться в появлении ID в `unknownQuests`, сделать `/reload` и проверить запись в файле. Затем перезайти на персонажа и проверить, что запись сохранилась. Эта проверка нужна отдельно от Lua-тестов.

Lua-проверки используют имитацию игровых API. Отрисовку, совместимость с другими аддонами и реальные ответы сервера нужно проверить в клиенте.

## Источники API

- [QuestLog, Forever](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/QuestLogDocumentation.lua)
- [QuestLine, Forever](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/QuestLineInfoDocumentation.lua)
- [MapCanvas, Forever](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_MapCanvas/Blizzard_MapCanvas.lua)

Сверка Зефриса: `research/zephras-import-audit.json`. Проверяется перенос полей из исходника ATT; полнота серверных условий этим не подтверждается. Импорт восстанавливает базовый уровень 1, который сборщик ATT убирает, и читает предметы начала заданий из `qss`.

Правило интерфейса: подсказки карты оформляются как штатные подсказки WoW. Название аддона, ID, сведения об ATT, причины фильтрации и прочая техническая диагностика показываются только в отчёте. На карте остаются название, уровень сложности и короткая полезная игроку информация.

## Принцип интерфейса

QuestRadar должен быть практически незаметным дополнением к большой карте WoW. Он подсказывает, где можно взять задания, и максимально следует оформлению и поведению интерфейса Blizzard.

Используем штатные значки, шрифты, цвета сложности, подсказки и элементы настроек. Обычная подсказка: `[уровень] Название`. Дополнительный текст нужен только тогда, когда помогает игроку принять решение. Не добавляем брендинг, панели поверх карты, объяснение внутренней логики или сообщения в чат при обычном использовании без конкретной необходимости. Техническая информация хранится в отчёте. Новые настройки добавляем только для реальной потребности.
